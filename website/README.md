# Web de Laura Díez Argos

Web estática bilingüe (ES / EN), sin dependencias. Abre `index.html` en el navegador para verla.

## Páginas
- `index.html` — Inicio: "My goal is to help you grow"
- `negocios.html` — Negocios
- `empleados.html` — Empleados
- `your-own-voice.html` — Podcast (YouTube, Instagram, Spotify)
- `contacto.html` — Contacto

## Qué editar
- **Textos (ES y EN):** `js/i18n.js`
- **Enlaces a redes, email, formulario y embeds:** `js/config.js`
- **Colores y tipografías:** variables al principio de `css/styles.css`
- **Tu foto:** guárdala en `img/laura.jpg` y sustituye el bloque `hero-photo` de `index.html`

## Publicarla
Se puede publicar gratis en Netlify, Vercel o GitHub Pages (carpeta `website/`) y conectar el dominio `lauradiezargos.com`.
